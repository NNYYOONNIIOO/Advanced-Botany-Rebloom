This project brings Advanced Botany to Minecraft 1.12.2. It is licensed under the [Botania License](https://botaniamod.net/license.html).

Building the optional Thaumcraft integration requires Thaumcraft 6.1.BETA26 at
`libs/[神秘时代] Thaumcraft-1.12.2-6.1.BETA26.jar`. Thaumcraft is not required
at runtime; the integration is enabled only when it is installed.
